Defense in depth

Countermeasures

No single control stops every attack. Effective security layers several defensive measures so that if one fails, others still protect you. Explore the core controls below.

🔑

Strong Passwords

Long, unique passphrases make guessing impractical and limit the damage of a leaked password.

  • Use 14+ characters or a multi-word passphrase
  • Never reuse passwords across accounts
  • Store them in a reputable password manager
📱

Multi-Factor Authentication (MFA)

Requires a second proof of identity, so a stolen password alone is not enough to log in.

  • Prefer authenticator apps or security keys over SMS
  • Enable it first on email, banking and cloud accounts
  • Store backup recovery codes safely
🧱

Firewalls

Filter network traffic according to rules, blocking unwanted connections and reducing exposure.

  • Deny by default, allow only what is needed
  • Use web application firewalls for public sites
  • Review rules regularly
🛡️

Antivirus / Endpoint Protection

Detects and blocks malicious software and suspicious behavior on laptops, phones and servers.

  • Keep definitions and agents updated
  • Enable real-time and behavior-based scanning
  • Alert on disabled protection
🔐

Encryption

Scrambles data so it is unreadable without the right key, both stored and in transit.

  • Use HTTPS and a VPN on untrusted networks
  • Enable full-disk encryption on devices
  • Protect and rotate encryption keys
🔄

Updates & Patch Management

Installing vendor fixes closes known vulnerabilities before they can be abused.

  • Enable automatic updates where possible
  • Prioritize critical and actively exploited fixes
  • Keep an inventory of software and devices
💾

Secure Backups

Reliable backups let you restore data after ransomware, hardware failure or accidental deletion.

  • Follow the 3-2-1 rule: 3 copies, 2 media, 1 offsite
  • Keep at least one offline or immutable copy
  • Test restores regularly
📡

Network Monitoring

Continuous visibility into logs and traffic reveals unusual behavior early, shortening response time.

  • Centralize logs for analysis
  • Alert on anomalies and failed logins
  • Use intrusion detection systems
🎓

Security Awareness Training

Helps people recognize phishing and manipulation, turning users into an active line of defense.

  • Train regularly, not just once
  • Run safe phishing simulations
  • Make reporting easy and blame-free
🚪

Access Control

Limits who can reach which systems and data, containing the impact of any compromised account.

  • Apply least privilege
  • Remove access promptly when roles change
  • Separate admin and everyday accounts
